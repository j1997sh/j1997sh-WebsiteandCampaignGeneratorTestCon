# Campaign Platform prototype

Static GitHub Pages prototype.

Main entry points:
- `index.html` — public product page
- `login.html` — demo login
- `dashboard.html` — campaign dashboard
- `websites.html` — website library
- `campaigns.html` — campaign microsites
- `creative.html` — social graphic templates
- `people.html` — lightweight supporter view
- `surveys.html` — survey builder
- `integrations.html` — CRM integrations

Upload the contents of this folder to the repository root.
